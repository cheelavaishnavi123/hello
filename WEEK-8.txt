. Click on topics-> your_topic -> publish message
. Write a message subject and write the message u want in message body section and click on publish message
YOU SHOULD SEE THE MESSAGE IN YOUR EMAIL

. Click on edit in your_topic(sns) -> click on access policy-> add

        } (see last in this .txt for clarity)
below the condition in access policy -> click on save changes
. go to s3-> buckets-> your bucket-> properties tab-> event notifications-> create event notification-> write a event name like uploadNotification-> click on all object create events checkbox-> click on SNS topic in destination->choose from your sns topics and select your topic-> save changes
