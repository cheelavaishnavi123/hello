CREATE AND ATTACH EBS VOLUME TO EC2 INSTANCE.

1. CREATE VOLUME

create ec2 (ubuntu) instance.

Open the EC2 Dashboard.
From the left-hand menu, select Volumes under Elastic Block Store (EBS).
Click Create Volume.
Choose:
Volume type (gp3/gp2)
Size of the volume
*Availability Zone (must be the same as the EC2 instance)
Click Create Volume.

2. ATTACH VOLUME

select volume -> click Actions -> Attach volume -> select EC2 instance
device name (/dev/xvdbf) -> click Attach

3. Verify 

Go to EC2 instacnce (meaning select that) in the details(storage) volume created will appear 
   (or)
select instance -> connect(using SSH) or just (EC2 Connect instance) click on the connect -> in the terminal type-  lsblk (attached volume displays).

4. Modify volume(scaling)

select volume -> click modify volume -> increase size -> modify

*( to change instance type dont need to stop the instance ).
