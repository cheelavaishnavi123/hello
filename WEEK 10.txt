USING .PHP
1) Prepare Your Application
	Make sure your PHP file index.php with content as below
        <?php
        // Hello World PHP Project
        echo "Hello World";
        ?>

2) Zip Your Project
	Store this file “index.php” in folder “demo” and make its zip file as “demo.zip”

3)Go to AWS Console-> search elastic beanstalk->click->create application
4)It will show create environemnt, go to applications in left console->create application
  fill the application name -> 3-web-app->click create
5)Click on Create Environment
 Step 1: Configure environment
      Environment → Web server environment
      Application name-> 3-web-app
      Platform** → Scroll down and choose your language (PHP.)
      Keep all default and Click on Next
 Step 2:
  Configure service access	
	Service role: LabRole
	EC2 instance profile: LaInstanceProfile
	EC2 key pair: Already create  key
	Press Next
 Step 3: Set up networking, database, and tags - optional 
         Keep all default-skip to review 
         Scroll down and click
6)Wait for some time 
  At Health -> Ok in Green must appear
  wait unitl enivironment successfully launched
7)Click the domain url-> website appears
8)Deploy your code 
	Click on **Upload and Deploy**
	Choose **Upload your code**
	Select your `.zip` file i.e. “demo.zip” created in Step 2
9)Click the domain- u will get 404 forbidden
  then add /demo at the url in the google
  eg: Yogita-web-app-env.eba-kp25kxcv.us-east-1.elasticbeanstalk.com
