create private subnet--priatesubnetforDatabase--10.0.2.0/24
2.Create Internet gateway
after creating attach it to your corresponding vpc i.r rajvpc
3.creating NAT gateway-->left side NAT gateway, click create NAT gateway and give name, that's it.
4.Create Route Table public subnet
 4.a Create RoutetablePublic
 4.b Attach Public Subnet(edit subnet association)
 4.c Edit Route: Attach internet gateway
 in edit route click addroute 0.0.0.0 and select internet gateway from dropdown and save chnages
5.Create Route Table private subnet
 5.a Create RouteTablePrivate
 5.b Attach Private Subnet
 5.c Edit Route (Add route: Destination :0.0.0.0/0 Target :Nat gateway)
6.creating privateDatabaseinstance
 a.keypair
 b.your vpc
 c.private subnet i.e privatesubnetforDatabase
 d.auto assign ip -->disable
 e.create security group --> add security rule :type:MYSQL/Aurora source type: my ip
launch instance-->copy private ipv4 address. 
7.creating publicBastioninstance 
 a.bastion keypair
 b.in network settings select your vpc(rajvpc), subnet->pulicsubnet which you created, enable autoassign ip
 c.create security group  add security rule :type:MYSQL/Aurora  source type: custom :give your private instance  ipv4 address
